Pagesmith privacy policy

Last updated: 8 November 2026

Summary

Pagesmith collects nothing, sends nothing and has no server.

What is stored, and where

  • Captures: the images you capture, with the page title, address and time. Stored in the extension's own storage (IndexedDB) on your computer. The newest 20 are kept by default, older ones are deleted automatically, and you can delete any capture from the viewer.
  • Settings: your choices on the options page, stored in Chrome's extension storage on your computer.

Uninstalling the extension deletes both.

What is sent

Nothing. The extension contains no code that makes network requests. You can check this yourself: the published package is reproducible from the open-source code, which is not minified, and its build pipeline fails if a network call is ever added.

Page access

Pagesmith uses Chrome's activeTab permission. It can access a tab only after you click its toolbar button or press its shortcut on that tab, and only until you navigate away. While capturing, it scrolls the page and temporarily hides floating elements, then puts the page back as it was. It does not read the page's text or content.

This website

This policy covers the extension. The website at bcollard.github.io/pagesmith is separate: it uses Google Analytics to count visits, which sets cookies in your browser and sends page views to Google. The extension does not include Google Analytics or any other network code.

Contact

Questions or concerns: open an issue on the project's GitHub repository.
