Pagesmith は、表示中のウェブページを画面に映っている部分だけでなく最後まで
まるごと取り込み、1 枚の画像または PDF として保存します。ツールバーの
ボタンをクリックするか Alt+Shift+S を押すと、ページが自動でスクロールし、
各部分が 1 枚の画像につなぎ合わされます。

記事の保存、デザインレビューの共有、長いダッシュボードのチケットへの添付、
領収書や予約内容の記録などに使えます。

主な機能
• ページの最上部から最下部までを 1 枚の画像に
• 固定ヘッダーやフローティングのチャットボタンは各画面ではなく上部に 1 回だけ表示
• 遅延読み込みの画像は取り込み開始前に読み込み
• 内側のパネルをスクロールするウェブアプリ(メール、チャット、ダッシュボード)も最後まで取り込み
• PNG または JPEG でダウンロード、A4・レター・内容に合わせたサイズの PDF、クリップボードへのコピー
• 非常に長いページは自動で複数の画像に分割し、PDF にはすべてを収録
• 最近の取り込みは拡張機能内に保存され、再ダウンロード可能
• ポップアップを閉じても処理を継続。進行状況はツールバーのアイコンに表示
• システム設定に合わせたダークモード
• 日本語、英語、フランス語、ドイツ語、スペイン語に対応

データはブラウザの外に出ません

取り込んだ画像はお使いのコンピューター上の、拡張機能専用の
ストレージにのみ保存され、古いものは自動で削除されます。Pagesmith は
ネットワーク通信を一切行いません。配布されるコードにはデータを送信する
手段が含まれておらず、それが変わった場合はビルドパイプラインのチェックが
失敗します。

インストール時にサイトへのアクセス許可を求めません

Pagesmith は Chrome の「アクティブなタブ」権限を使用します。ボタンを
クリックしたタブだけを、そのページから移動するまでの間だけ参照できます。
「すべてのウェブサイト上にある自分の全データの読み取りと変更」の確認は
表示されません。

オープンソースで、ビルドを検証できます

ソースコードは MIT ライセンスで GitHub に公開されています。各リリースは
そのソースからバイト単位で再現でき、署名付きの来歴証明(プロベナンス
アテステーション)が付いているため、インストールしたものが公開されたもの
と同一であることを確認できます。

制限事項
• Chrome の仕様により、どの拡張機能も Chrome 自身のページ(chrome://…)や他の拡張機能のページは取り込めません
• Chrome ウェブストア上では表示中の範囲のみ取り込めます
• 無限スクロールのフィードは、オプションで設定した高さ(既定は 40,000 ピクセル)で停止します
