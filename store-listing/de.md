Pagesmith erfasst die ganze Webseite, die Sie gerade ansehen — nicht nur den
sichtbaren Ausschnitt — und speichert sie als ein einziges Bild oder als PDF.
Klicken Sie auf die Schaltfläche in der Symbolleiste oder drücken Sie
Alt+Umschalt+S; die Seite scrollt von selbst, und die Abschnitte werden zu
einem Bild zusammengefügt.

Praktisch, um einen Artikel zu archivieren, ein Design-Review zu verschicken,
ein langes Dashboard an ein Ticket anzuhängen oder eine Quittung oder Buchung
festzuhalten.

FUNKTIONEN
• Die ganze Seite, von oben bis unten, in einem Bild
• Fixierte Kopfzeilen und schwebende Chat-Schaltflächen erscheinen einmal oben statt auf jedem Abschnitt
• Nachgeladene Bilder werden vor Beginn der Aufnahme geladen
• Web-Apps, die einen inneren Bereich scrollen (Mail, Chat, Dashboards), werden vollständig erfasst
• Download als PNG oder JPEG, PDF in A4, Letter oder an den Inhalt angepasst, oder Kopieren in die Zwischenablage
• Sehr hohe Seiten werden automatisch in mehrere Bilder aufgeteilt, die alle im PDF enthalten sind
• Die letzten Aufnahmen bleiben in der Erweiterung gespeichert und können erneut heruntergeladen werden
• Läuft weiter, wenn Sie das Pop-up schließen; der Fortschritt erscheint auf dem Symbol in der Symbolleiste
• Dunkelmodus entsprechend Ihrer Systemeinstellung
• Deutsch, Englisch, Französisch, Spanisch und Japanisch

NICHTS VERLÄSST IHREN BROWSER

Aufnahmen werden nur auf Ihrem Computer im eigenen Speicher der Erweiterung
abgelegt, ältere werden automatisch gelöscht. Pagesmith stellt überhaupt keine
Netzwerkanfragen: Der ausgelieferte Code enthält keine Möglichkeit, Daten zu
senden, und eine Prüfung in der Build-Pipeline schlägt fehl, falls sich das
jemals ändert.

BEI DER INSTALLATION WERDEN KEINE WEBSITES ANGEFORDERT

Pagesmith nutzt die Chrome-Berechtigung „aktiver Tab“. Die Erweiterung sieht
nur den Tab, in dem Sie auf ihre Schaltfläche klicken, und nur bis Sie die
Seite verlassen. Es gibt keine Abfrage „Alle Ihre Daten auf allen Websites
lesen und ändern“.

OPEN SOURCE, UND DER BUILD IST ÜBERPRÜFBAR

Der Quellcode steht unter der MIT-Lizenz auf GitHub. Jede Version ist aus
diesem Quellcode Byte für Byte reproduzierbar und trägt eine signierte
Herkunftsbestätigung (Provenance Attestation). So können Sie prüfen, dass das
Installierte dem Veröffentlichten entspricht.

GRENZEN
• Chrome erlaubt keiner Erweiterung, eigene Seiten (chrome://…) oder Seiten anderer Erweiterungen zu erfassen
• Im Chrome Web Store selbst kann nur der sichtbare Bereich erfasst werden
• Endlose Feeds stoppen bei einer Höhe, die Sie in den Optionen festlegen (standardmäßig 40.000 Pixel)
